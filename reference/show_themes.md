# Return available themes in the European Social Survey

This function returns the available themes in the European Social
Survey. However, contrary to
[`show_countries`](https://docs.ropensci.org/essurvey/reference/show_countries.md)
and
[`show_country_rounds`](https://docs.ropensci.org/essurvey/reference/show_country_rounds.md),
themes can not be downloaded as separate datasets. This and
[`show_theme_rounds`](https://docs.ropensci.org/essurvey/reference/show_theme_rounds.md)
serve purely for informative purposes.

## Usage

``` r
show_themes()
```

## Value

character vector with available themes

## Examples

``` r

if (FALSE) { # \dontrun{
show_themes()
} # }
```
